# Main Menu / Home Redesign (Workstream A) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the sparse placeholder Home with a real main menu: a title treatment plus **Begin Investigation**, **Continue** (most-recently-played puzzle, hidden without history), and **Settings** entries.

**Architecture:** A testable `MainMenuScreen` component renders the title block + menu `Button`s, driven by props (`onBegin`/`onContinue`/`onSettings`/`showContinue`). The Home route (`src/app/index.tsx`) keeps the onboarding redirect, derives the Continue target from `progressStore` (`solved[*].lastPlayedAt` max), and wires the handlers to navigation. Regions → Puzzle List stays the selector.

**Tech Stack:** React Native + Expo Router, TypeScript, Jest + `@testing-library/react-native` v13. Reuses the `Button` atom. No new deps; only `expo-router` navigation (already in use — `useRouter`/`Redirect`, unchanged API).

## Global Constraints

- Never inline color/spacing/font values; import from `@/theme`. (project convention)
- Home keeps redirecting to `/onboarding` while `progressStore.onboardingCompleted === false`; hooks are called before the conditional return (rules of hooks). (SCREEN_SPECS.md Screen 1; existing behavior)
- **Continue** targets the puzzle id with the largest `lastPlayedAt` in `progressStore.solved`; the button is hidden when `solved` is empty. (design doc)
- Menu entries: **Begin Investigation** → `/regions`; **Continue** → `/puzzle/{id}`; **Settings** → `/settings`. (design doc)
- `@testing-library/react-native` is v13 — synchronous `render`/`fireEvent`; the `Button` atom uses `expo-haptics` on press (mock it in tests that press). Reset `progressStore` in `beforeEach`. (project convention)

- [ ] **Step 1: Rewrite the Home route**

Replace `src/app/index.tsx` with:
```tsx
import React, { useMemo } from 'react';
import { useRouter, Redirect } from 'expo-router';
import { useProgressStore } from '@/state';
import { MainMenuScreen } from '@/components/screens';

export default function Home() {
  const router = useRouter();
  const onboardingCompleted = useProgressStore((s) => s.onboardingCompleted);
  const solved = useProgressStore((s) => s.solved);

  const continueId = useMemo(() => {
    let best: string | undefined;
    let bestAt = -Infinity;
    for (const [id, entry] of Object.entries(solved)) {
      if (entry.lastPlayedAt > bestAt) {
        bestAt = entry.lastPlayedAt;
        best = id;
      }
    }
    return best;
  }, [solved]);

  if (!onboardingCompleted) {
    return <Redirect href="/onboarding" />;
  }

  return (
    <MainMenuScreen
      testID="home-screen"
      showContinue={continueId !== undefined}
      onContinue={() => {
        if (continueId) router.push(`/puzzle/${continueId}`);
      }}
      onBegin={() => router.push('/regions')}
      onSettings={() => router.push('/settings')}
    />
  );
}
```
